가족 그룹 생성 / 초대

온보딩 · 최초 1회

목적

  • 앱의 정체성인 "닫힌 가족 피드"를 시작하는 진입점. 외부와 완전히 분리된 그룹 단위를 먼저 만든다.

주요 구성요소

  • 그룹 이름 입력 (기본값 "우리 가족", 수정 가능)
  • 호칭 선택 칩 — 피드에서 이름 대신 호칭으로 표시(딸/아들/엄마/아빠/기타)
  • 초대 링크 공유 버튼(카카오톡) — 네이티브 공유 시트 호출
  • 초대 현황 리스트 — 참여완료 / 초대장 발송됨 상태 표시

인터랙션

  • 공유 버튼 탭 → 웹뷰가 네이티브 앱 셸에 공유 인텐트 요청 → 카카오톡 공유 시트 오픈
  • 초대받은 가족이 링크로 참여 수락 시, 목록의 상태가 "초대장 발송됨" → "참여완료"로 실시간 갱신
  • "그룹 만들고 시작하기" 탭 → 화면2(메인 피드)로 이동

데모 범위: 사전준비(40%)에서 UI 골격 + 기본 CRUD, 스프린톤 데이(85%)에서 실시간 상태 갱신까지 구현.

메인 피드

코어 화면 · 하단 탭 1번

목적

  • 안부·일정·건강 3영역이 하나의 타임라인에 통합되고, 글마다 "누가 확인했는지"가 바로 보이는 것이 카톡 대비 핵심 차별점.

주요 구성요소

  • 그룹 전환 드롭다운 + 알림 벨
  • 구성원 아바타 스토리 행 (온라인 상태 표시용)
  • 유형 필터 칩(전체/안부/일정/건강)
  • 리마인드 하이라이트 카드 — 가족 이벤트 D-day, 별색 배경으로 구분
  • 유형별 카드 — 색상 태그(안부=파랑/일정=초록/건강=주황) + 읽음 확인 아바타 스택
  • + 플로팅 버튼(글쓰기), 하단 탭 바

인터랙션

  • 카드 탭 → 화면4(읽음 확인 상세)로 이동
  • 필터 칩 탭 → 해당 유형만 필터링
  • + 버튼 탭 → 화면3(글쓰기)로 이동, 리마인드 카드의 "축하 메시지 남기기" → 화면6으로 이동

읽음 확인은 실시간성이 핵심 가치라 소켓/폴링으로 갱신. 무한스크롤 페이지네이션 적용.

글 작성 (3유형)

피드 + 버튼으로 진입 · 모달/스택 화면

목적

  • 안부·일정·건강 3유형을 하나의 작성 화면에서 다루되, 유형별로 입력 폼이 달라지는 구조.

주요 구성요소 및 유형별 차이

  • 안부(표시된 상태) — 자유 텍스트 + 사진 첨부
  • 일정 — 날짜/시간 선택기 + 제목 입력 폼으로 전환
  • 건강 — 카테고리 칩(복약/검진/증상) + 날짜 + 메모 폼으로 전환
  • 공통: "할 일로도 등록하기" 토글 — 켜면 화면5(할 일)에도 동시 등록

인터랙션

  • 상단 세그먼트(안부/일정/건강) 탭 → 하단 입력 폼 전체가 교체됨
  • "게시" 탭 → 피드 최상단에 새 카드로 추가, 화면2로 복귀

경량 AI(선택 기능): 본문 입력 시 유형 자동 추천, 일정 텍스트에서 날짜·할 일 자동 추출.

읽음 확인 상세

피드 카드 탭 시 진입 · 스택 화면

목적

  • "봤는지·챙겼는지가 남는다"는 서비스의 핵심 가치를 가장 직접적으로 보여주는 화면. 구성원별 확인 여부와 시각을 명시적으로 노출.

주요 구성요소

  • 게시물 원문 + 작성자/시간/유형 태그
  • 읽음 확인 리스트 — 확인함(시각 포함) / 안 읽음(회색 처리)을 구성원별로 명확히 구분
  • 댓글 스레드 + 하단 고정 댓글 입력창

인터랙션

  • 화면 진입 시 자동으로 "읽음" 이벤트 발생 → 본인 상태가 "확인함"으로 갱신되고 다른 가족의 피드 카드에도 실시간 반영
  • 안 읽은 구성원에게는 추후 알림(푸시)으로 리마인드 가능 (Phase2 검토)

본선 데모 핵심 시연 포인트: 2~3개 계정으로 동시에 열어 읽음 상태가 실시간으로 바뀌는 것을 직접 보여준다.

할 일 등록·체크

하단 탭 2번

목적

  • 피드에서 흘러가는 대신, "챙겨야 할 일"을 리스트로 남기고 완료 여부를 가족이 함께 확인하게 만드는 화면.

주요 구성요소

  • 이번주 진행률 바 (완료/전체)
  • 기간 필터 칩(오늘/이번주/전체)
  • 날짜별 그룹핑된 할 일 리스트 — 체크박스, 담당자, 완료 시 취소선 처리
  • 화면3에서 "할 일로도 등록" 토글 켠 게시물, 화면6 리마인드에서 파생된 항목도 여기 함께 표시

인터랙션

  • 체크박스 탭 → 즉시 완료 처리 + 담당자 이름 옆에 "완료" 표시, 피드/리마인드 화면에도 반영
  • + 버튼 → 할 일 직접 추가 모달

데모 시연 포인트: 한 구성원이 체크하면 다른 기기(다른 가족 계정)에서도 실시간으로 체크 표시가 바뀌는 것을 보여준다.

생일/기념일 자동 리마인드

하단 탭 3번 · 피드 하이라이트 카드와 연동

목적

  • 가족 이벤트를 능동적으로 검색하지 않아도 자동으로 알려주는 화면. 결제·구매 유도가 아니라 "챙길 일을 놓치지 않게" 하는 데 집중.

주요 구성요소

  • D-day 카운트다운 카드, 지난해 기록 회상 문구(간단 요약)
  • 구성원별 준비 현황(완료/대기) — 서로 챙기고 있는지 알 수 있게
  • 액션 버튼: "축하 메시지 남기기"(댓글 작성으로 이동) / "할 일로 등록"(화면5에 항목 추가)
  • 다가오는 이벤트 목록 미리보기

인터랙션

  • "할 일로 등록" 탭 → 화면5에 해당 이벤트 관련 할 일이 자동 생성되어 담당자 지정 가능
  • 피드(화면2) 상단 하이라이트 카드 탭 → 이 화면으로 진입

방침: 결제·구매·제휴 상품 노출은 하지 않는다. 수익화(가족 단위 이벤트 제휴 등)는 별도 확장 단계(Phase2)에서 검토하며, 이 화면은 UX 기능으로만 존재한다.
