가족방 생성

온보딩 1단계 · 초대보다 반드시 먼저 수행

목적

  • 가족방의 최소 정보만 입력해 서버에 방을 먼저 생성하고 생성자를 방장으로 확정한다.

생성 규칙

  • 가족방 이름과 생성자의 호칭은 필수 입력이다.
  • 생성 버튼을 누르면 방 ID와 방장 권한이 생성되고 성공 응답 후 화면2로 이동한다.
  • 생성 전에는 초대 링크를 만들거나 가족을 초대할 수 없다.
  • 무료 방 3개를 이미 보유했다면 생성 직전에 방 추가권 구매를 안내한다.

오류 처리

  • 네트워크 오류 시 방이 생성되지 않았음을 명확히 표시하고 중복 생성을 막는다.
  • 생성 성공 후 초대 화면을 닫더라도 가족방은 유지되며 방 관리에서 다시 초대할 수 있다.

생성과 초대를 하나의 저장 동작으로 묶지 않는다. 방 생성 성공을 확정한 뒤에만 초대 링크 발급 API를 호출한다.

오늘의 가족 피드

홈의 ‘피드 보기’로 진입 · 오늘 게시물 전체

목적

  • 오늘 가족들이 올린 모든 글·사진·영상을 누락 없이 시간순으로 확인한다.

주요 구성요소

  • 오늘 날짜와 전체 게시물 수
  • 오늘의 질문
  • 작성자·시각·본문·미디어·반응이 포함된 피드
  • 질문으로 기록하기와 하단 중앙 + 버튼

매일 질문 푸시

  • 매일 가족 구성원에게 하나의 질문을 푸시한다.
  • 예: “오늘 하루 중 제일 힘들었던 순간은 언제였나요?”, “오늘 날씨가 마음에 드시나요?”, “오늘 가장 고마웠던 사람은 누구인가요?”
  • 질문은 감정에 한정하지 않고 일상·날씨·취향·관계·회상·가벼운 선택형 등 다양한 주제를 반복되지 않게 순환한다.
  • 알림 탭 시 화면5 오늘 기록하기로 이동하며 질문을 작성 화면 상단에 유지한다.

질문에 답하지 않아도 자유 기록을 올릴 수 있고, 미작성자에게 반복 독촉하거나 참여율을 공개하지 않는다.

  • ‘하루 종일’이 켜지면 시간 선택기를 숨기고 시작일·종료일만 표시한다.

인터랙션

  • 종료 일시는 시작 일시보다 빠를 수 없으며 여러 날 일정도 지원한다.
  • 메모에는 준비물·예약 정보·이동 방법 등 가족이 함께 확인할 세부사항을 입력한다.

  • 설정에 저장한 생일은 매년 자동 생성하며 🔒로 표시한다. 일정 화면에서는 수정·삭제할 수 없다.
